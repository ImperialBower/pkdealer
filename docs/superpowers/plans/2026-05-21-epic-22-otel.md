# EPIC-22 OTel Instrumentation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Instrument `pkdealer_service` with OpenTelemetry (hand/street/action spans + four metrics), ship a `docker compose` stack (service + collector + Jaeger + Prometheus + Grafana) that brings the full backend online in one shot.

**Architecture:** Service installs a W3C TraceContext propagator and pushes OTLP traces + metrics over gRPC to an `otel-collector` container; collector fans out to Jaeger (traces) and a Prometheus-exporter endpoint (metrics). Span hierarchy is `hand → street → action`, with action spans parented to incoming `traceparent` (agent-future) or to the in-process street span (no-agent default).

**Tech Stack:** `tracing` 0.1, `tracing-subscriber` 0.3, `tracing-opentelemetry` 0.31, `opentelemetry` / `opentelemetry_sdk` / `opentelemetry-otlp` 0.30, `tracing-test` 0.2 (dev), `cargo-chef` (Dockerfile), `otel/opentelemetry-collector-contrib` 0.115.1, `jaegertracing/all-in-one` 1.62, `prom/prometheus` v2.55.1, `grafana/grafana` 11.3.1.

**Spec:** [`docs/superpowers/specs/2026-05-20-epic-22-otel-design.md`](../specs/2026-05-20-epic-22-otel-design.md)

use opentelemetry::propagation::Extractor;
use tonic::metadata::MetadataMap;

/// Newtype adapter implementing [`Extractor`] over an incoming
/// [`MetadataMap`], used by the W3C TraceContext propagator to read
/// `traceparent` / `tracestate` headers from gRPC metadata.
pub struct MetadataExtractor<'a>(pub &'a MetadataMap);

impl<'a> Extractor for MetadataExtractor<'a> {
    fn get(&self, key: &str) -> Option<&str> {
        self.0.get(key).and_then(|v| v.to_str().ok())
    }

    fn keys(&self) -> Vec<&str> {
        self.0
            .iter()
            .filter_map(|kv| match kv {
                tonic::metadata::KeyAndValueRef::Ascii(k, _) => Some(k.as_str()),
                tonic::metadata::KeyAndValueRef::Binary(_, _) => None,
            })
            .collect()
    }
}
```

use opentelemetry::global;
use opentelemetry_otlp::{MetricExporter, SpanExporter, WithExportConfig};
use opentelemetry_sdk::{
    metrics::SdkMeterProvider,
    propagation::TraceContextPropagator,
    trace::SdkTracerProvider,
    Resource,
};
use tracing_opentelemetry::OpenTelemetryLayer;
use tracing_subscriber::{layer::SubscriberExt, util::SubscriberInitExt, EnvFilter, Registry, fmt};

pub struct OtelGuards {
    tracer_provider: SdkTracerProvider,
    meter_provider:  SdkMeterProvider,
}

impl Drop for OtelGuards {
    fn drop(&mut self) {
        let _ = self.tracer_provider.shutdown();
        let _ = self.meter_provider.shutdown();
    }
}

pub fn init_otel() -> Result<Option<OtelGuards>, Box<dyn Error>> {
    if std::env::var("OTEL_SDK_DISABLED").as_deref() == Ok("true") {
        // Install a plain fmt subscriber so logs still appear.
        Registry::default()
            .with(EnvFilter::try_from_default_env()
                .unwrap_or_else(|_| EnvFilter::new("pkdealer_service=info,info")))
            .with(fmt::layer())
            .init();
        return Ok(None);
    }

    let endpoint = std::env::var("OTEL_EXPORTER_OTLP_ENDPOINT")
        .unwrap_or_else(|_| "http://localhost:4317".to_owned());
    let service_name = std::env::var("OTEL_SERVICE_NAME")
        .unwrap_or_else(|_| "pkdealer_service".to_owned());

    // 1. Install global W3C TraceContext propagator.
    global::set_text_map_propagator(TraceContextPropagator::new());

    let resource = Resource::builder().with_service_name(service_name).build();

    // 2. Tracer provider with batched OTLP gRPC exporter.
    let span_exporter = SpanExporter::builder()
        .with_tonic()
        .with_endpoint(&endpoint)
        .build()?;
    let tracer_provider = SdkTracerProvider::builder()
        .with_resource(resource.clone())
        .with_batch_exporter(span_exporter)
        .build();
    let tracer = tracer_provider.tracer("pkdealer_service");

    // 3. Meter provider with periodic OTLP gRPC exporter.
    let metric_exporter = MetricExporter::builder()
        .with_tonic()
        .with_endpoint(&endpoint)
        .build()?;
    let meter_provider = SdkMeterProvider::builder()
        .with_resource(resource)
        .with_periodic_exporter(metric_exporter)
        .build();
    global::set_meter_provider(meter_provider.clone());

    // 4. tracing-subscriber: env filter + fmt + OTel layer.
    Registry::default()
        .with(EnvFilter::try_from_default_env()
            .unwrap_or_else(|_| EnvFilter::new("pkdealer_service=info,info")))
        .with(fmt::layer())
        .with(OpenTelemetryLayer::new(tracer))
        .init();

    Ok(Some(OtelGuards { tracer_provider, meter_provider }))
}
```

## EPIC-22 — OpenTelemetry Instrumentation

**Status: ✅ Complete**

### What was built

- `crates/pkdealer_service/src/otel.rs` — `init_otel()`, `OtelGuards`,
  `MetadataExtractor`. W3C TraceContext propagator + OTLP gRPC trace +
  metric exporters; `OTEL_SDK_DISABLED=true` short-circuits init for
  tests and CI.
- Span hierarchy in `pkdealer_service`:
  - `hand` span — opened in `start_hand`, closed on `SessionStep::HandComplete`.
  - `street` span — opened on each `SessionStep::StreetAdvanced`, parent =
    current hand span.
  - `action` span — opened in `act` handler; parent selected from
    incoming `traceparent` when present, otherwise from
    `current_street_span` for service-internal nesting.
- Four metrics: `pkdealer.hands_played` (counter),
  `pkdealer.pot_size` (histogram, chips),
  `pkdealer.action_duration_ms` (histogram, ms,
  attributes `action_type` + `seat`), and
  `pkdealer.ai_decision_latency_ms` (histogram, ms, **reserved for
  EPIC-23 agents** — service does not emit).
- `crates/pkdealer_service/Dockerfile` — multi-stage `cargo-chef` build,
  non-root user, default `OTEL_EXPORTER_OTLP_ENDPOINT=http://otel-collector:4317`.
- `docker-compose.yml` — service + `otel-collector` + Jaeger + Prometheus +
  Grafana. Backends bind to host ports `16686`, `9090`, `3001`,
  plus collector OTLP on `4317`.
- `ops/otel-collector.yaml`, `ops/prometheus.yml`, hand-authored
  `ops/grafana/dashboards/pkdealer.json` with 6 panels (hands/min, pot
  heatmap, action latency quantiles, action mix, agent latency placeholder,
  Jaeger link).

### Architecture

```
service → OTLP/gRPC → otel-collector → Jaeger (traces) + Prometheus exporter
                                                              ↑
                                                  Prometheus scrapes :8889
                                                              ↑
                                                       Grafana queries Prom
```

### Notes

- Action-span parent selection: when EPIC-23 agents inject `traceparent`,
  action spans become children of the agent span; service-internal
  cross-reference is preserved via the `linked_hand_trace` recorded
  field (a true OTel span-link can replace this when the SDK API
  stabilises).
- The "AI decision latency" panel is intentionally empty until EPIC-23
  ships.
