# EPIC-44 Phase 1 — Per-seat Token Accumulator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add live per-seat LLM token aggregation to `pkdealer_service`, surfaced on the `SeatInfo` proto, with an in-repo debug log and OpenTelemetry gauges.

**Architecture:** Mirror the existing `banked_profit` accumulator. A new `TableState.session_tokens: HashMap<u8,(u64,u64)>` is incremented on the accepted-action path via a pure helper, populated onto `SeatInfo` by `build_table_status`, exported via two OTel gauges, and logged once per seat at hand end.

**Tech Stack:** Rust, prost/tonic (gRPC + protobuf), OpenTelemetry, tracing.

/// Adds one accepted action's LLM token counts to a seat's running total.
///
/// Increments `acc[seat]` by `(input, output)` only when **both** counts are
/// present; a missing count (bot action, or partial fidelity) is a no-op so bots
/// never appear in the map. Mirrors the `banked_profit` accumulator shape.
///
/// # Examples
/// ```ignore
/// let mut acc = std::collections::HashMap::new();
/// accumulate_session_tokens(&mut acc, 2, Some(1200), Some(8));
/// assert_eq!(acc.get(&2).copied(), Some((1200, 8)));
/// ```
fn accumulate_session_tokens(
    acc: &mut std::collections::HashMap<u8, (u64, u64)>,
    seat: u8,
    input: Option<u32>,
    output: Option<u32>,
) {
    if let (Some(i), Some(o)) = (input, output) {
        let entry = acc.entry(seat).or_default();
        entry.0 += u64::from(i);
        entry.1 += u64::from(o);
    }
}
```

(The doctest is `ignore` because the fn is private; the `#[test]` cases above are the real coverage. If the crate's lint config forbids `ignore` doctests, drop the `# Examples` block — the unit tests satisfy coverage.)
